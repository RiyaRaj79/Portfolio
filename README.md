# Portfolio
Riya Raj | Interaction Design Portfolio



I'm Riya, a Computer Science student at SRM Institute of Science and Technology. I design and build interfaces that make small everyday decisions easier. This repo holds my portfolio site.

What's inside

Case studies

FreshKeep: a smart pantry companion that helps households use food before it spoils. Covers the information architecture, the three-state freshness system, one-tap actions and an AI food assistant. Code
BudgetBuddy: a budget outing planner that turns "what can we do for ₹500?" into five easy choices, with live per-person trade-offs. Try it live | Code

Each case study shows real screens with numbered design notes, followed by what I'd change and what I'd test next.

Other work: a real-time CCTV safety monitoring system (Tata Steel internship) and a Google Play ratings analysis (Elevance Skills internship).

How it's built
One self-contained index.html file: HTML, CSS and a few lines of JavaScript, with no frameworks or build step
Screenshots are embedded in the page, so there are no separate image files
Responsive from phone to desktop, with light and dark mode
Fonts: Archivo and Kalam (Google Fonts)
Hosted on GitHub Pages
Run it locally

Download index.html and open it in any browser.
