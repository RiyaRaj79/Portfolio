Voice translator

Speech-to-speech translation for Indian languages that keeps the speaker's own voice, instead of swapping it for a stock text-to-speech voice.

You speakany supported language
Transcribefaster-whisper
TranslateNLLB / IndicTrans
Speak backF5-TTS voice clone

Why I picked it

Most translation apps flatten everyone into the same synthetic voice. In a phone call or a family conversation, hearing the actual person matters. It also forced me to work across three separate models and deal with latency at each hand-off.

Build log

  • Day 1Speech-to-English-speech pipeline working end to end
  • Day 2Voice cloning so the output sounds like the original speaker
  • Day 3 to 4Browser front end and a custom UI for recording and playback
  • Day 5Tested text translation from English to Hindi, Tamil and Telugu with NLLB and IndicTrans (about 0.3 s per sentence with NLLB)
  • Day 6Now trying IndicF5 for more natural Indian-language speech
  • NextReal-time streaming under one second, a live two-person web app, and audio watermarking so cloned voices can be identified

FreshKeep

A pantry tracker that warns you before food goes off and has an assistant that actually knows what's in your kitchen.

What it does

  • Add items with a category, quantity and expiry date. Each item is sorted by days left:
Fresh Expiring soon Expired
  • Separate views for the pantry, alerts, recipe ideas and stats by category.
  • Items can be marked as used or flagged for donation, so the stats reflect what was saved rather than just what was thrown away.
  • A chat assistant answers questions like "what can I cook tonight?" using the current pantry.

How the assistant works

Before each message, the app builds a short summary of the pantry (what's there, what's expiring, what's expired) and puts it in the system prompt. A small Express server forwards the request to Llama 3.3 70B on Groq, so the API key stays on the server and never reaches the browser.

BudgetBuddy

Tell it your budget, group size and mood, and it puts together a day out that you can actually afford.

How it works

The front end sends budget, group size and mood to a POST /plan endpoint. The server picks from activities for that mood (eight options, from chill to cultural to party), multiplies each cost by the group size, and adds activities only while the total stays under budget. It returns the plan, the total and the cost per person.
